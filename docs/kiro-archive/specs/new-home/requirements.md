# Requirements Document

## Sprout ホーム画面要件定義書 (v1.0.0)

### 1. 概要

本ドキュメントは、子育て・家族写真共有アプリ「Sprout」のホーム画面におけるUI/UXを再定義するものである。既存の単純なリスト形式から、月ごとの思い出を美しく振り返り、かつ過去のデータへのアクセスを最適化する構造へと刷新する。

### 2. 機能要件

#### 2.1 デフォルト表示機能

- **カレント表示**: アプリ起動時、常にサーバーサイドの時刻に基づいた「当月」の画像一覧を表示する。
- **Featured Section**: 画面最上部に、その月を象徴する一枚（代表画像）を大きく強調して配置する。

#### 2.2 月次ナビゲーション機能

- **タブ構造**: 画面上部に月（1月、2月、3月...）のタブを横並びで配置する。
- **スワイプ連動**: タブのタップだけでなく、画面の左右スワイプによって月間の移動を可能にする。

#### 2.3 アーカイブ・ドリルダウン機能

- **Yearly Hub**: タブの最左端に「全ての画像/年別」ボタンを設置する。
- **年次タイル**: 過去の画像を年ごとのタイル形式（例：2024, 2025, 2026）で一覧表示する。
- **階層遷移**: 特定の「年」をタップすると、その年の「1月」から「12月」までの月次タブが展開される構造とする。

### 3. UI/UX 仕様

| 要素            | 仕様詳細                                                                                                                      |
| :-------------- | :---------------------------------------------------------------------------------------------------------------------------- |
| **Hero Image**  | 閲覧数、または「お気に入り」数に基づきアルゴリズムで自動選出された画像を、アスペクト比を保ちつつ画面上部1/3~1/2の領域で表示。 |
| **Month Tabs**  | スクロール可能なタブ。現在選択されている月がハイライトされる。                                                                |
| **Image Grid**  | 代表画像以下の写真は、3カラム程度のグリッド形式で整列。                                                                       |
| **Yearly View** | 各年を代表する1枚をサムネイルとしたカード形式で表示。                                                                         |

### 4. データロジック

#### 4.1 代表画像選出アルゴリズム

代表画像（Main Visual）は以下の優先順位で自動選定する。

1. **ユーザー指定**: ユーザーが手動で「今月のカバー」に設定した画像。
2. **エンゲージメント**: お気に入り（Like）数が最も多い画像。
3. **ビュー数**: 特定期間内に閲覧された回数が最も多い画像。
4. **フォールバック**: 上記データがない場合は、その月の最新の画像を適用する。

#### 4.2 ディレクトリ構造（アーカイブ）

`ALL (Yearly Tiles)` -> `Selected Year (Monthly Tabs)` -> `Images (Grid)`

この3階層により、数千枚の画像が存在する場合でも、目的の年月に3タップ以内で到達できる設計とする。
