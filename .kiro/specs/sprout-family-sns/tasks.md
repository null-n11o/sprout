# Implementation Plan: Sprout Family SNS

## Tasks

- [ ] 1. プロジェクト初期セットアップ
- [ ] 1.1 Next.js プロジェクトの作成と基本設定
  - Next.js 14 (App Router) + TypeScript でプロジェクト初期化
  - Tailwind CSS の設定とカスタムテーマ（カラーパレット、M PLUS Rounded 1c フォント）
  - 基本的なレイアウトコンポーネント（ヘッダー、ナビゲーションバー）
  - ESLint、Prettier の設定
  - _Requirements: 6.1_

- [ ] 1.2 PWA 設定
  - next-pwa の導入と Service Worker 設定
  - manifest.json の作成（アプリ名、アイコン、テーマカラー）
  - オフラインフォールバックページ
  - _Requirements: 1.1_

- [ ] 2. データベース・認証基盤
- [ ] 2.1 Supabase プロジェクトセットアップ
  - Supabase プロジェクトの作成と接続設定
  - 環境変数の設定（SUPABASE_URL, SUPABASE_ANON_KEY）
  - Supabase クライアントの初期化
  - _Requirements: 4.1_

- [ ] 2.2 データベーススキーマの作成
  - profiles, children, posts, growth_records, reactions, comments テーブル作成
  - 外部キー制約とインデックスの設定
  - 初期データの投入（カイリ、稀の子供データ）
  - _Requirements: 5.1_

- [ ] 2.3 Row Level Security (RLS) ポリシーの設定
  - 全テーブルで RLS を有効化
  - 認証済みユーザーのみアクセス可能なポリシー設定
  - 投稿・コメントの所有者のみ編集・削除可能なポリシー
  - _Requirements: 2.1_

- [ ] 2.4 Magic Link 認証の実装
  - Supabase Auth の Magic Link 設定
  - ログイン画面の作成
  - 認証状態の管理（Context/Provider）
  - 認証ガードコンポーネント
  - _Requirements: 2.1_

- [ ] 3. ストレージ基盤（Cloudflare R2）
- [ ] 3.1 (P) R2 バケットと API Route の設定
  - Cloudflare R2 バケットの作成と認証情報設定
  - AWS SDK を使用した R2 クライアント初期化
  - Presigned URL 発行 API エンドポイントの作成
  - ファイルパス規約の実装（children/{child_id}/{year}/{month}/{filename}）
  - _Requirements: 3.2_

- [ ] 4. タイムライン機能
- [ ] 4.1 投稿一覧 API の作成
  - 投稿取得 API（カーソルベースページネーション）
  - 子供フィルタリング機能
  - 投稿に紐づくリアクション・コメント数の取得
  - _Requirements: 3.1_

- [ ] 4.2 タイムライン UI の作成
  - 無限スクロールのタイムラインフィード
  - 投稿カード（写真/動画、キャプション、投稿日、月齢表示）
  - 子供フィルター切り替え UI（全員/カイリ/稀）
  - 月齢計算ユーティリティの実装
  - _Requirements: 3.1_

- [ ] 5. アップロード & AI 代筆機能
- [ ] 5.1 画像アップロード機能
  - アップロードフォーム UI（写真選択、子供選択、キャプション入力）
  - Presigned URL を使用したダイレクトアップロード処理
  - アップロード進捗表示
  - 投稿作成 API の実装
  - _Requirements: 3.2_

- [ ] 5.2 AI キャプション自動生成機能
  - Gemini API クライアントの設定
  - 画像解析とキャプション生成ロジック
  - 非同期処理（投稿作成後にバックグラウンドで生成）
  - Realtime でキャプション更新を反映
  - _Requirements: 3.2_

- [ ] 6. 身体測定ログ機能
- [ ] 6.1 (P) 成長記録 API の作成
  - 成長記録の CRUD API エンドポイント
  - 子供別の記録取得
  - 入力バリデーション（身長・体重の範囲チェック）
  - _Requirements: 3.3_

- [ ] 6.2 (P) 成長記録入力フォーム
  - 身長・体重入力フォーム UI
  - 日付選択と子供選択
  - メモ入力機能
  - _Requirements: 3.3_

- [ ] 6.3 成長グラフの作成
  - 身長・体重の時系列グラフコンポーネント
  - 子供別のグラフ切り替え
  - グラフライブラリの導入と設定
  - _Requirements: 3.3_

- [ ] 7. リアクション機能
- [ ] 7.1 (P) いいね機能
  - いいねトグル API の作成
  - ハートボタン UI（アニメーション付き）
  - Realtime でいいね数の即時反映
  - _Requirements: 3.4_

- [ ] 7.2 (P) コメント機能
  - コメント CRUD API の作成
  - コメント一覧表示 UI
  - コメント投稿フォーム
  - Realtime でコメントの即時反映
  - _Requirements: 3.4_

- [ ] 8. 統合・仕上げ
- [ ] 8.1 ナビゲーションとルーティング
  - 下部固定タブバーの実装（ホーム/投稿/成長記録/設定）
  - 各ページへのルーティング設定
  - ページ遷移アニメーション
  - _Requirements: 6.1_

- [ ] 8.2 エラーハンドリングと UI 改善
  - グローバルエラーハンドリング
  - ローディング状態の表示
  - 空状態の表示（投稿がない場合など）
  - トースト通知の実装
  - _Requirements: 1.1_

- [ ] 8.3 E2E テストの作成
  - 認証フローのテスト
  - 写真アップロード → タイムライン表示のテスト
  - 成長記録入力 → グラフ反映のテスト
  - いいね・コメント操作のテスト
  - _Requirements: 3.1, 3.2, 3.3, 3.4_
