# Implementation Plan

## 新ホーム画面 実装タスク

### API Layer

- [x] 1. 代表画像・年別一覧APIの実装
- [x] 1.1 (P) 代表画像選出APIを実装する
  - 月ごとの代表画像を選出して返すエンドポイントを作成
  - Like数が最も多い画像を優先し、なければ最新画像をフォールバック
  - 子どもIDによるフィルタリングに対応
  - 画像がない月は null を返す
  - _Requirements: 2.1, 4.1_
  - _Contracts: FeaturedAPI_

- [x] 1.2 (P) 年別一覧APIを実装する
  - 画像が存在する年の一覧を取得するエンドポイントを作成
  - 各年の代表サムネイル（年内で最もLike数が多い画像）を含める
  - 写真枚数のカウントを含める
  - 子どもIDによるフィルタリングに対応
  - _Requirements: 2.3, 4.2_
  - _Contracts: YearsAPI_

### UI Components - Foundation

- [x] 2. ホーム画面コンテナの実装
- [x] 2.1 ホーム画面の状態管理とレイアウトを構築する
  - 現在表示中の年月状態を管理
  - 表示モード（月別表示/年別アーカイブ）の切り替え機能
  - 子どもフィルター状態の管理
  - 既存のChildFilterコンポーネントを統合
  - アプリ起動時にサーバー時刻から当月を取得して初期表示
  - _Requirements: 2.1, 2.2, 2.3_
  - _Contracts: HomePageState_

### UI Components - Display

- [x] 3. 画像表示コンポーネントの実装
- [x] 3.1 (P) 代表画像（Hero Image）表示コンポーネントを実装する
  - 画面上部1/3〜1/2の領域に代表画像を大きく表示
  - アスペクト比を維持した表示
  - 画像がない場合のプレースホルダー表示
  - Next.js Imageによる最適化配信
  - _Requirements: 2.1, 3_
  - _Contracts: HeroImage, FeaturedAPI_

- [x] 3.2 (P) 写真グリッドを既存コンポーネントと統合する
  - 既存PhotoGridコンポーネントを新ホーム画面に統合
  - 代表画像を除いた写真一覧を3カラムグリッドで表示
  - 月別APIからデータを取得
  - タップで詳細モーダル表示（既存機能を利用）
  - _Requirements: 2.1, 3_
  - _Contracts: PhotoGrid, MonthlyAPI_

### UI Components - Navigation

- [x] 4. 月次ナビゲーションの実装
- [x] 4.1 月タブコンポーネントを実装する
  - 1月〜12月のタブを横スクロール可能な形式で表示
  - 現在選択中の月をハイライト表示
  - タブタップで該当月に切り替え
  - 画像が存在しない月はグレーアウト表示
  - 左端に「全年表示」ボタン（Yearly Hub）を配置
  - _Requirements: 2.2, 3_
  - _Contracts: MonthTabsProps_

- [x] 4.2 スワイプによる月間移動を実装する
  - Framer Motionのドラッグジェスチャーで左右スワイプを検出
  - 横方向50px以上のスワイプで月移動判定
  - 12月から1月へのスワイプで年+1、1月から12月で年-1
  - 月切り替え時のスライドアニメーション
  - _Requirements: 2.2_

### UI Components - Archive

- [x] 5. 年別アーカイブ機能の実装
- [x] 5.1 年別タイル一覧コンポーネントを実装する
  - 画像が存在する年をタイル形式で一覧表示
  - 各年タイルに代表サムネイルと写真枚数を表示
  - 年タップで該当年の1月に遷移
  - アニメーション付きのモード切り替え
  - _Requirements: 2.3, 3, 4.2_
  - _Contracts: YearlyArchive, YearsAPI_

### Integration

- [x] 6. 全体統合と仕上げ
- [x] 6.1 ホーム画面を既存アプリに統合する
  - 既存のタイムラインフィード画面を新ホーム画面に置き換え
  - 3階層ナビゲーション（年→月→写真）の動作確認
  - 子どもフィルターとの連携動作確認
  - エラー状態の表示（写真なし、ネットワークエラー）
  - _Requirements: 2.1, 2.2, 2.3, 4.2_

- [x] 6.2 パフォーマンス最適化を行う
  - 初期表示1秒以内を目標にLCP最適化
  - 月切り替え300ms以内のレスポンス
  - グリッド画像の遅延読み込み
  - APIレスポンスのキャッシュ戦略
  - _Requirements: 3_

### Testing

- [ ] 7. テストの実装
- [ ] 7.1 (P) APIのテストを実装する
  - 代表画像選出ロジックの単体テスト（Like数優先、フォールバック）
  - 年別一覧APIのレスポンス検証
  - 子どもIDフィルタリングの動作確認
  - _Requirements: 4.1_

- [ ] 7.2 (P) UIコンポーネントのテストを実装する
  - 月タブの状態管理テスト
  - スワイプジェスチャーの判定テスト
  - 表示モード切り替えのテスト
  - _Requirements: 2.2, 2.3_

- [ ]* 7.3 Playwrightを利用して、E2Eテストを実装する
  - ホーム画面初期表示（当月表示）の確認
  - 月タブ・スワイプによる月移動の確認
  - 年別アーカイブからのドリルダウンの確認
  - _Requirements: 2.1, 2.2, 2.3, 4.2_
