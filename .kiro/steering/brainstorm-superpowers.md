# Sprout スーパーパワー ブレインストーム

> 作成日: 2026-03-29
> 目的: Sprout に追加できる「あったら最高」な機能・体験のアイデア集

---

## 🌱 カテゴリ 1: AI × 記録の革新

### SP-01: 成長日記AI自動生成（月次サマリー）
毎月末に、その月の写真・成長記録・コメントをもとにAIが「今月のまとめ日記」を自動生成。親が何もしなくても月次記録が完成する。
- **技術**: Gemini Pro + Supabase Scheduled Functions（pg_cron）
- **インパクト**: ★★★★★（コア価値の強化）

### SP-02: 写真からマイルストーン自動検出
「初めて立った！」「初めて食べた！」などをAIが写真から推測し、マイルストーン候補を提案。親は承認するだけ。
- **技術**: Gemini Vision API による画像分析
- **インパクト**: ★★★★☆

### SP-03: 成長曲線AIアドバイス
身長・体重データを入力すると、厚生労働省の成長曲線と比較し「同月齢の平均的な成長と比べて…」とAIがコメント。（医療アドバイスではなく参考情報として）
- **技術**: Gemini + 標準成長曲線データ
- **インパクト**: ★★★☆☆

### SP-04: 「今日の一言」AI生成プッシュ通知
子供の誕生日から月齢を計算し、「今日で生後〇日！ちょうど〇ヶ月前の今日は…」と過去写真を引用しながらAIが一言メッセージを生成してプッシュ通知する。
- **技術**: Web Push API + Gemini + Service Worker
- **インパクト**: ★★★★☆（エンゲージメント向上）

---

## 📸 カテゴリ 2: 思い出体験の強化

### SP-05: タイムカプセルメッセージ
「〇歳の誕生日に開封」できるメッセージ・写真ボックス。家族が今の気持ちを未来の子供へ向けて記録する。
- **技術**: Supabase + 日時条件付きの公開ロジック
- **インパクト**: ★★★★★（感情的インパクト最大）

### SP-06: 誕生日フォトブック自動生成
誕生日が近づくと、その年の写真を自動でコラージュした「フォトブックPDF」を生成してダウンロードできる。
- **技術**: Canvas API / jsPDF + S3画像
- **インパクト**: ★★★★☆

### SP-07: 「同じ日の去年」機能
ホーム画面に「1年前の今日」セクションを追加。同じ日付の過去写真を自動でハイライト表示する（Googleフォト風）。
- **技術**: Supabase クエリ（同月同日フィルタ）
- **インパクト**: ★★★★★（実装コスト低 × 感動度高）

### SP-08: 子供目線の成長比較スライダー
同一子供の生後1ヶ月 vs 現在の写真を左右スライダーで比較表示する。
- **技術**: 画像比較UIコンポーネント
- **インパクト**: ★★★☆☆

---

## 👨‍👩‍👧‍👦 カテゴリ 3: 家族コミュニケーション

### SP-09: 家族クイズ機能
「この写真、何歳何ヶ月のとき？」「この場所どこ？」などのクイズを自動生成し、家族で楽しめる。
- **技術**: Gemini（クイズ生成）+ Supabase（回答管理）
- **インパクト**: ★★★☆☆（エンゲージメント向上）

### SP-10: リアクションの多様化
ハートだけでなく「泣いた😢」「笑った😂」「成長した🌱」などのスタンプリアクションを追加。絵文字リアクション集計グラフも表示。
- **技術**: reactions テーブルに type カラム追加
- **インパクト**: ★★★★☆

### SP-11: 音声メッセージコメント
テキストコメントに加え、祖父母が音声メッセージを録音して送れる機能。「おじいちゃんの声で『大きくなったね！』」
- **技術**: Web Audio API + S3 ストレージ + 音声プレイヤーUI
- **インパクト**: ★★★★☆（祖父母UX向上）

### SP-12: 家族ランキング（投稿数・コメント数）
「今月一番投稿したのは〇〇さん！」「いいねの数が多かった写真ランキング」など、ゲーミフィケーション要素。
- **技術**: Supabase 集計クエリ
- **インパクト**: ★★★☆☆

---

## 📊 カテゴリ 4: データ活用・可視化

### SP-13: 成長ビジュアルタイムライン
縦軸に年齢・月齢、横軸に各種イベント（写真投稿・マイルストーン・身体測定）を並べた統合タイムライン表示。
- **技術**: recharts または カスタムSVG
- **インパクト**: ★★★★☆

### SP-14: 思い出ヒートマップ
GitHubのcontribution graph風に、月ごとの投稿数・家族アクション数をヒートマップ表示。「思い出の濃さ」を可視化。
- **技術**: カスタムSVGグリッドコンポーネント
- **インパクト**: ★★★☆☆

### SP-15: 写真のキーワードタグ自動付与
Gemini が写真を解析し「公園」「お風呂」「ご飯」「笑顔」などのタグを自動付与。タグ検索で横断的に写真を探せる。
- **技術**: Gemini Vision + Supabase 全文検索 / `tags[]` カラム
- **インパクト**: ★★★★☆（検索体験向上）

---

## 🔔 カテゴリ 5: エンゲージメント・ライフサイクル

### SP-16: 月齢マイルストーン通知
「生後100日おめでとう！」「もうすぐ1歳！」などのマイルストーン日に自動プッシュ通知を送信する。
- **技術**: Web Push + pg_cron（Supabase）
- **インパクト**: ★★★★☆

### SP-17: 未記録アラート
「先月の写真がまだ0枚です！」など、記録が少ない月に対してやさしくリマインドする機能。
- **技術**: Service Worker + Supabase 統計クエリ
- **インパクト**: ★★★☆☆

### SP-18: 誕生日カウントダウン
ホーム画面に次の誕生日まで何日か表示。誕生日当日は特別なアニメーション演出。
- **技術**: Framer Motion + 日付計算
- **インパクト**: ★★★☆☆（実装コスト低）

---

## 🔒 カテゴリ 6: プライバシー・セキュリティ強化

### SP-19: データエクスポート機能
全写真・テキストデータをZIP形式でエクスポートできる。「サービスが終了しても思い出は守られる」という安心感。
- **技術**: S3 一括ダウンロード + ZIP生成（JSZip）
- **インパクト**: ★★★★★（信頼性向上）

### SP-20: 顔認識による子供別自動タグ付け
写真に写っている子供を自動で識別し、子供ごとにフィルタリングできる（プライバシー設定で無効化可能）。
- **技術**: Gemini Vision / AWS Rekognition
- **インパクト**: ★★★☆☆（プライバシーリスク要検討）
